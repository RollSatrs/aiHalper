# БЫСТРОЕ ИСПРАВЛЕНИЕ ОШИБКИ

## Проблема
Пакет `react-router-dom` не установлен, поэтому сайт не работает.

## Решение (выберите один способ):

### Способ 1: Запустите install-router.bat
Просто дважды кликните на файл `install-router.bat` в папке проекта.

### Способ 2: Через CMD (Command Prompt)
1. Нажмите `Win + R`
2. Введите `cmd` и нажмите Enter
3. Выполните команды:
   ```
   cd C:\Users\Владос\Desktop\aihelper-front
   npm install react-router-dom
   ```

### Способ 3: Через проводник
1. Откройте папку проекта в проводнике
2. В адресной строке введите `cmd` и нажмите Enter
3. Выполните: `npm install react-router-dom`

## После установки
Перезапустите dev-сервер:
- Остановите текущий (Ctrl+C)
- Запустите снова: `npm run dev`

Готово! Ошибка должна исчезнуть.
