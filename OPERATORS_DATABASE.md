# 👥 Что нужно для операторов в базе данных

## ✅ Что УЖЕ есть:

### 1. **Таблица `users`** - операторы хранятся там:
- `role = 'operator'` - роль оператора
- `name`, `email`, `password` - данные для входа
- Авторизация работает через JWT

### 2. **Защита эндпоинтов:**
- `OperatorGuard` - проверяет что пользователь оператор
- Только операторы могут видеть сложные тикеты
- Только операторы могут редактировать черновики и закрывать тикеты

### 3. **Операторы видят:**
- Все сложные тикеты (`is_simple = false`)
- Summary и draftResponse для каждого тикета
- Могут редактировать и отправлять ответы
