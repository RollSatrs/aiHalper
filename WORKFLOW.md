# ✅ Полный Workflow сервиса (реализовано)

## 🧑‍💼 Шаг 1: Пользователь отправляет заявку

**Endpoint:** `POST /api/tickets/create`

**Request:**
```json
{
  "message": "Не могу подключиться к корпоративному Wi-Fi — пишет неправильный пароль"
}
```

## 🤖 Шаг 2: Backend вызывает OpenAI для классификации

**Что происходит:**
- ИИ анализирует заявку
- Определяет: категорию, отдел, приоритет, является ли проблема типовой

**Пример ответа ИИ:**
```json
{
  "category": "Сеть / Wi-Fi",
  "department": "IT Support",
  "priority": "Средний",
  "is_simple": true
}
```

## ⚡ Шаг 3: Сервис проверяет: проблема типовая?

### ✅ Если `is_simple = true` (типовая проблема):

**Что происходит:**
1. ИИ генерирует пошаговую инструкцию
2. Тикет автоматически закрывается (`status: "closed_auto"`)
3. Пользователь получает автоответ с инструкцией

**Пример автоответа:**
```
✅ Ваш запрос решён автоматически! 👌

📋 Инструкция по решению:

1. Откройте настройки Wi-Fi
2. Выберите сеть CORP-WIFI
3. Используйте пароль, указанный в корпоративном портале
4. Если ошибка повторяется — сбросьте настройки сети

💡 Если проблема останется — просто ответьте в чат, и заявка откроется снова.
```

**Тикет сохраняется с:**
- `status: "closed_auto"`
- `autoSolved: true`
- `autoSolution: "инструкция..."`
- `responseTime: <время в секундах>`

---

### 📋 Если `is_simple = false` (сложная проблема):

**Пример сложной заявки:**
```
"После обновления сервера 1С перестали проводиться документы, ошибка 502 при синхронизации"
```

**ИИ классифицирует:**
```json
{
  "category": "1С",
  "department": "1С Development",
  "priority": "Высокий",
  "is_simple": false
}
```

**Что происходит:**
1. ИИ создает **summary** (краткое резюме для оператора)
2. ИИ создает **черновик ответа** для оператора
3. Тикет отправляется в отдел (`status: "in-progress"`)

**Пример summary:**
```
Коротко: после обновления сервера 1С не проводится документ, ошибка 502. Требует проверки логов синхронизации.
```

**Пример черновика ответа:**
```
Здравствуйте!

Мы получили ваше обращение. Ошибка 502 может возникать из-за сбоя при обновлении сервера.

Мы передали запрос специалистам 1С, они помогут в ближайшее время.

С уважением,
Служба поддержки Казахтелеком
```

**Пользователь получает:**
```
📨 Ваше обращение получено!

✅ Оно передано в отдел "1С Development".

👨‍💼 Специалисты свяжутся с вами в ближайшее время.
```

## 🎯 API Endpoints

### Создание тикета
- `POST /api/tickets/create` - создание новой заявки

### Получение тикетов
- `GET /api/tickets` - все тикеты
- `GET /api/tickets/complex` - только сложные тикеты (для TODO-листа операторов)
- `GET /api/tickets/:id` - тикет по ID

### Работа оператора
- `PATCH /api/tickets/:id/draft` - обновить черновик ответа
- `PUT /api/tickets/:id/resolve` - закрыть тикет (пометить как решенный)

### Dashboard
- `GET /api/dashboard` - метрики работы системы

## 🏁 Демонстрация на хакатоне

### 1️⃣ Простой сценарий (авторешение)
1. Открываете форму → пишете: "Не могу подключиться к Wi-Fi"
2. ИИ моментально классифицирует → `is_simple: true`
3. ИИ дает пошаговую инструкцию
4. Тикет автоматически закрывается
5. Пользователь видит решение сразу

### 2️⃣ Сложный сценарий (ручная обработка)
1. Открываете форму → пишете: "После обновления сервера 1С ошибка 502"
2. ИИ классифицирует → `is_simple: false`
3. Тикет отправляется в отдел "1С Development"
4. ИИ создает summary и черновик ответа
5. Оператор видит тикет в TODO-листе админки
6. Оператор может отредактировать черновик и отправить ответ

### 3️⃣ Мониторинг
1. Открываете панель админа (`/admin`)
2. Видите метрики:
   - Общее количество заявок
   - Процент автоответов
   - Среднее время ответа
   - Точность классификации
   - Ошибки маршрутизации
